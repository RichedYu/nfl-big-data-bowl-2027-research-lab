# 数据审计

竞赛数据实测待完成。本页记录审计口径，每次完整运行生成独立报告。

- 文件身份包括字节数与 SHA-256。严格读取所有行，解析异常直接报错。
- 缺失标记包括空值、`NA`、`N/A`、`NULL`、`NaN`，字符列另计纯空格。百分比使用所在文件总行数。
- 候选主键检查空键与重复。关联检查分别统计匹配、空键、孤立行、孤立键和父表覆盖。重复父键按键统计覆盖，避免将多重匹配计作多条子表记录。
- 球员唯一数排除 SQL 空值。分组输出位置、选秀年、训练项目、追踪试次数、重复试次覆盖、帧数范围和比赛追踪覆盖。
- 试次短片段、时间缺失和重复时间可由报告定位到分组。帧数只能初筛轨迹完整性。10 Hz 实际间隔、`dis` 与坐标路径长度、测量方向及训练起止定义需要在原始数据上进一步核对。
- 位置组研究排序依据实测有效球员数、重复测量和结果指标可得性。
