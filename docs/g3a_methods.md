# G3A movement measurement and availability policy

This stacked change prepares a development evidence package for scientific review. Movement screening compares common-interior raw coordinate chord sums with local-quadratic reconstruction. Stationary and slow synthetic controls test false motion introduced by coordinates. The private pre-outcome protocol specifies coverage, perturbation and stability gates for two candidates. Neither candidate is authorized for the real-outcome model under those gates.

The restricted policy comparison covers the full 2023 draft WR/TE roster and the historical common-player subset. Outcome access is restricted to the 2023 roster and rookie REG. R is publication eligibility. Y is observed conditional mean separation. Technical tracking availability represents data coverage and validity rules. Roster and forty fallback keep players with missing inputs in the target population. Repeated grouped splits and weighted player-bootstrap refits preserve original player identities. Paired loss and calibration values remain private.

## Reproduce privately

Use the authorized Cloud workspace, optional scientific dependencies from G2.3 and a private directory containing the frozen protocol. The runner verifies prior checkpoints and stage artifacts. Use a writable Matplotlib cache.

```bash
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python scripts/g3a_run.py "$run" measurement models mechanism
.venv/bin/python scripts/g3a_annotation.py --cases cases.csv --private-clusters private_cluster_map.json reviewer_A.csv reviewer_B.csv agreement.json
```

The comparison can consume partial submissions. Completed, unjudgeable and blank cases have distinct denominators. Full event matching requires overlap and annotated center. Partial matches are reported separately using two shared timed anchors. The coordinator's private cluster map keeps repeated cases of a player together for resampling, and is withheld from reviewers. Match statistics are available only after real reviewers submit labels.
