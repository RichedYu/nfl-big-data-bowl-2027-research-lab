# G3A-R1 multiscale measurement

The measurement-only follow-up preserves the earlier G3A decisions. Compare endpoint displacement rate at fixed spans with the derivative of a fitted trajectory and a geometry measure built from sparse path nodes. Compare each operator to its own noiseless construct and separately to physical instantaneous speed. Static and sustained speed controls have their own thresholds. A coarse geometry certificate does not qualify transient movement measurements.

The analytical audit verifies expected accumulated distance under isotropic Gaussian position noise for raw differences and five-point location reconstruction. The data reference audit uses 2023 Combine rows only. Official tracking speed is a same-source comparison. Electronic split validation requires trial linkage, start and finish landmark support, and clock alignment.

Run privately in the authorized workspace with the archived G3A and G1 source checkpoints. Prepare a new ignored run directory containing the frozen protocol and run:

```bash
.venv/bin/python scripts/g3ar1_run.py "$run" analytic measurement reference
.venv/bin/python -m unittest discover -s tests -v
```
